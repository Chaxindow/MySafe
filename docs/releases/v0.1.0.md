**MySafe 0.1.0 — first public release** 🎉

A simple, open-source password manager for Windows and Linux that works from your computer
**and** from a USB stick and keeps both copies in sync. No account, no cloud, no internet.

### Download

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `MySafe.exe` |
| Linux (x86-64) | `MySafe-linux-x86_64` — run `chmod +x MySafe-linux-x86_64` first |

Each file has a `.sha256` checksum next to it. Windows: `Get-FileHash MySafe.exe` in
PowerShell; Linux: `sha256sum -c MySafe-linux-x86_64.sha256`.

> Windows may say "Windows protected your PC" because the program is not code-signed yet:
> click **More info → Run anyway**.

### What's inside

- Categories and entries with your own fields: email, username, password, recovery codes,
  security questions, notes
- Search, favorites, one-click copy (cleared from the clipboard automatically), password
  generator, light/dark theme
- Strong encryption: AES-256-GCM + Argon2id, master password + recovery key
- Lock (Ctrl+L) and optional auto-lock
- **USB copy and Sync** with a side-by-side view of changes, red deletion markers and
  backups before every sync
- **Restore from backup**

### Getting started

1. Start the program and choose a master password.
2. **Write down the recovery key** it shows you — it's your only way back in if you forget
   the password.
3. Read the [user guide](https://github.com/Chaxindow/MySafe/blob/main/docs/USER_GUIDE.md)
   for USB sync, backups and more.
